Questions

What buyers ask first.

What file do you need?

A data file with one row per label, together with the artwork. Tell us what changes and we confirm the format.

Can each label carry a different QR code?

Yes. QR codes can change on every label.

Can labels of a limited edition be numbered?

Yes, with sequential numbering.

Can variable data be combined with foil and relief?

Yes. Variable data is printed digitally; finishing is applied on top.
