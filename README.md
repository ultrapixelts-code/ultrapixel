# UltraPixel website

Static site, generated by `build.py` from `content/en.json` and published by Render from this branch.

- **Change copy, work tiles, photos:** edit `content/en.json`, put images in `assets/`, run `python3 build.py`, commit.
- **Add a language:** create `content/it.json` (same keys), add `"it"` to `LANGS` in `build.py`. It is published under `/it/` with hreflang links.
- **Development build (default):** every page carries `noindex`.
- **Launch build:** set `site.launchUrl` in `content/en.json` (the real domain), then `python3 build.py --launch`.
  This removes `noindex` and rewrites canonical URLs, sitemap, robots.txt and structured data to the real domain.
- **AI crawlers:** `robots.txt` allows `OAI-SearchBot` and `ChatGPT-User`. Set `site.blockAiTraining` to `true` to add `GPTBot: Disallow`.
- **Contacts and forms:** fill `site.email`, `site.phone`, `site.linkedin`, `site.instagram`, `site.formEndpoint`.
- The scroll sequence on the homepage lives in `src/film.*`.
