# UltraPixel website

Static site, generated by `build.py` from `content/en.json` and published by Render from this branch.

- **Change copy, work tiles, photos:** edit `content/en.json`, put images in `assets/`, run `python3 build.py`, commit.
- **Add a language:** create `content/it.json` (same keys), add `"it"` to `LANGS` in `build.py`. It is published under `/it/` with hreflang links.
- **Development build (default):** every page carries `noindex`.
- **Launch build:** set `site.launchUrl` in `content/en.json` (the real domain), then `python3 build.py --launch`.
  This removes `noindex` and rewrites canonical URLs, sitemap, robots.txt and structured data to the real domain.
- **AI crawlers:** `robots.txt` allows `OAI-SearchBot` and `ChatGPT-User`. Set `site.blockAiTraining` to `true` to add `GPTBot: Disallow`.
- **Contacts and forms:** fill `site.email`, `site.phone`, `site.linkedin`, `site.instagram`, `site.formEndpoint`.
- **Local search (JSON-LD LocalBusiness):** every page carries a LocalBusiness for Trieste and one per office. Optional: `site.sameAs`
  (other public profiles, e.g. the Google Business Profile link), `site.openingHours` (schema.org format, e.g. `"Mo-Fr 08:00-17:00"`),
  `site.geo` (`[latitude, longitude]`); the same `openingHours`, `geo`, `telephone`, `email` can be set on each office. Empty values are not published.
- **Language:** root-language pages show a small banner offering the visitor's browser language; nobody is redirected automatically.
- **llms.txt:** written by the build from the site's own copy (who UltraPixel is, sectors, technologies, offices, key links).
- **.htaccess (site root, not generated):** 301/410 for the pages of the previous ultrapixel.it, www → without www, http → https,
  `/index.html` → folder, custom 404. If the hosting already has a root .htaccess, paste this one at the top of it.
- The scroll sequence on the homepage lives in `src/film.*`.

## Launch checklist

1. `python3 build.py --launch`, commit, push. Canonical URLs, sitemap, robots.txt and structured data switch to `https://ultrapixel.it`.
2. In Render, add the custom domain `ultrapixel.it` to this static site and point DNS to it.
   Add `www.ultrapixel.it` as well and set it to redirect (301) to `ultrapixel.it`; check with `curl -I https://www.ultrapixel.it/`.
3. `robots.txt` allows `OAI-SearchBot` and `ChatGPT-User` and blocks `GPTBot` (`site.blockAiTraining`).

## Request forms

Forms record: timestamp, source page, landing page, sector, request type, referrer, utm_source, utm_medium, utm_campaign
(`assets/lead.js`, kept in sessionStorage for the visit, no cookies). With no backend they open the visitor's mail app addressed to `site.email`.
Set `site.formEndpoint` to POST the same fields as JSON to a backend.
